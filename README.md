# ICCP Summer School on Computational Imaging

Website of the ICCP Summer School on Computational Imaging: every course offered at the school since 2025, with links to course materials, plus photos and sponsors from each edition. Served by GitHub Pages at https://school.iccp-conference.org.

To preview locally, run `python3 -m http.server 8000` in this directory and open http://localhost:8000.

Before committing, run `python3 tools/check_site.py`. See `CLAUDE.md` for the site architecture and a checklist for adding a new edition.
